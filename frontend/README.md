# Arthrakshak Frontend 🎨

This repository contains the user interface for **Arthrakshak**, built with React 19 and Vite.

## Author & Contributor
- **Raman Kumar**

## Features
- Dynamic financial dashboards & interactive charts
- Expense hub and credit card management modules
- AI Assistant drawer and financial health insights

## Scripts
- `npm run dev`: Start local development server
- `npm run build`: Build for production
- `npm run preview`: Preview production build locally
